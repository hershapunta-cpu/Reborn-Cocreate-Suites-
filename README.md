# ReBoRn Co-Create Suite

Quote builder, ROI simulator, 90-day roadmap and creative brief builder for ReBoRn Marketing Solution Agency.

## Publish on GitHub Pages
1. Create a new public repository (for example `cocreate`).
2. Upload every file in this folder, keeping the `icons` folder. Commit to the `main` branch.
3. Open Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Install on a phone
Open the link in Chrome (Android) or Safari (iPhone) and choose Add to Home Screen.

## Notes
- Data saves in the browser of each device only.
- The repository is public, so the files, including the business phone number in the quote text, are visible to anyone.
- Quote prices are starter placeholders. Edit them before sending quotes.
